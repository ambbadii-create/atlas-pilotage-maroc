# Atlas Pilotage Maroc

Build the initial interface for a professional French-language web application named "Pilotage CG", designed for contrôle de gestion in Moroccan companies.

Create a premium SaaS dashboard inspired by modern financial management platforms.

DESIGN:

- Desktop-first responsive interface.

- Navy blue sidebar, white background, subtle blue accents.

- Professional typography, clean tables, rounded KPI cards, and elegant charts.

- Currency: MAD (DH).

- All interface labels in French.

SIDEBAR:

1. Tableau de bord

2. Budgets & Prévisions

3. Stocks & Approvisionnements

4. Achats & Fournisseurs

5. Ventes & Clients

6. Comptabilité & Analyse financière

7. Coûts & Rentabilité

8. Trésorerie

9. Reporting

10. Administration

MAIN DASHBOARD:

- KPI cards for chiffre d'affaires, charges, résultat net, trésorerie, marge nette, and stock valorisé.

- Monthly revenue and profit chart.

- Budget versus actual chart.

- Expense breakdown.

- Stock alerts.

- Budget variance alerts.

- Recent transactions table.

Use clearly labelled illustrative demo data.

Create a polished, consistent layout with reusable components.

Make the sidebar navigation work between pages, and provide attractive initial placeholder pages for each module.

For now, focus on the visual interface and navigation. Do not claim that database operations or financial calculations are implemented until they actually work.
